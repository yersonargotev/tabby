# Open Decisions

There are no unresolved architecture decisions for the current Session Runtime.
The accepted contract is defined by [CONTEXT.md](../../CONTEXT.md) and
[ADR 0010](../adr/0010-adopt-session-owned-runtime-for-herdr-0.8.md).

New product or architecture uncertainty must be recorded in a GitHub issue
before it becomes implementation work. Historical startup, global-state, and
one-shot designs remain in their superseded ADRs and research records; they do
not define current behavior.
