# Use a canonical production plugin root

The repository root is Tabby's canonical production-shaped Herdr plugin root for GitHub-managed installation and local linking. Every root startup hook, event, and action invokes one stable `.herdr/bin/tabby` executable contract; local contributors prepare it explicitly from a debug build because `herdr plugin link` does not run manifest build commands, while distribution-specific preparation stays behind the same path. Homebrew remains an alternative adapter with its packaged binary path, but manifest validation requires identical product semantics and permits only documented build and executable-path differences. This supersedes ADR 0005's decision to keep the root manifest development-only without changing Session Runtime behavior or storing plugin configuration or Session-Scoped Tab State inside the source root.
